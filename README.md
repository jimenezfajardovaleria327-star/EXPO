# Práctica Hadoop MapReduce: Estadística de Palabras

## Requisitos
- Tener Docker instalado y un contenedor llamado `hadoop` creado con Hadoop 3.3.6.

## Cómo ejecutarlo
1. Clona este repositorio:
   ```bash
    git clone https://github.com/jimenezfajardovaleria327-star/EXPO.git
   cd EXPO 
docker start hadoop
docker cp ejecutar.sh hadoop:/tmp/ejecutar.sh
docker exec -it hadoop bash /tmp/ejecutar.sh
```
